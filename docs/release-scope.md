# 公开发布范围与维护边界

本仓库包含 project-relay 与 shared-project-memory 两个可独立安装、配合使用的技能。公开版本保留原有命令行行为，调整安装路径、Python 入口及面向接收者的说明，不改变本机原始安装。以下边界适用于当前及后续公开发布，不只是一次性的首次发布记录；每次更新仍以用户当时的授权为准。

## 验收边界

- Python CLI：共享记忆保存、读取、关键词检索、项目与分支隔离；接力任务创建、接管、检查点、审核基线与执行拒绝。
- PowerShell 5.1 CLI：中文及含空格目录、明确指定的 Python 可执行文件、缺失运行时的清楚报错。显式指定的无效 Python 必须报错，不能悄悄回退。
- 运行时选择：两个技能各自提供 Python 环境变量覆盖；未配置时使用当前用户的 Codex bundled Python。无需修改系统 PATH、安装 pip 包或调整用户模型路由。
- 执行器回归使用临时目录中的模拟程序，验证超时、并发与进程清理；测试不调用真实模型、不读取用户真实凭据。可选的 `cc_switch_db` 只以只读方式读取当前网关令牌，读取失败或令牌缺失时拒绝执行，不回退旧凭据。
- 分发只包含技能代码、通用文档、配置示例和测试；排除个人记忆库、真实项目协作记录、凭据、缓存和作者专用路径。
- project-relay 所有命令仅支持 Windows，现有 Windows 进程树保护保持；本次不增加其他系统支持、不增加插件市场或自动安装器。
- GitHub Actions 在 `windows-latest` 上以 Python 3.10 和 3.12 运行标准库测试，只读仓库内容，不安装 pip 依赖、不读取用户配置、不调用模型。CI 通过不代替真实认证或真实执行验证。

## 持续维护

维护流程见 [project-relay 维护说明](../skills/project-relay/references/maintenance.md)：确认基线、先回归后实现、按授权提交推送、按 SHA 跟踪 CI 到结束、同步技能安装副本并做真实最小任务验证。更新说明和维护入口同步维护在根 `README.md`；个人数据库、密钥和执行日志始终不发布。

## 依赖

Python 3.10+ 标准库；使用 Git 项目身份和审核基线时需要 Git。PowerShell 入口适用于 Windows PowerShell 5.1+。project-relay 的实际自动派活需要 Windows、Claude Code 和当前实现支持的 CC Switch 桌面代理配置，由使用者自行配置并承担模型调用费用。
