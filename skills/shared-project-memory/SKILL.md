# 共享项目记忆

由当前会话模型整理摘要，本地脚本负责保存与检索。Codex 和 Claude Code（包括 DeepSeek 后端）共用一套记录。按当前用户授权读取和保存项目摘要；安装本技能不代表用户已授权自动保存。仅消耗当前会话的模型用量。

## 入口

根据当前技能文件的位置定位脚本。以下 Windows PowerShell 命令相对技能根目录运行，项目参数使用实际项目的绝对路径：

```powershell
$memory = Join-Path (Get-Location) 'scripts\memory.ps1'
& $memory --project '实际项目目录' context
& $memory --project '实际项目目录' recall --limit 5
& $memory --project '实际项目目录' search --query '相机 超时' --limit 5
& $memory --project '实际项目目录' save --agent codex --title '阶段说明' --file '摘要的绝对路径.md'
```

Claude Code 保存时用 `--agent claude`，即使后端为 DeepSeek。两端读取均不按 agent 过滤。

PowerShell 入口优先使用环境变量 `SHARED_PROJECT_MEMORY_PYTHON` 指定的 Python 可执行文件；未配置时使用当前用户的 Codex bundled Python。缺失时明确报错，请用户配置 Python 3.10+ 的绝对路径。直接运行 `memory.py` 时也使用已确认的 Python。脚本只使用标准库，无需 pip、额外模型 API 或 MCP。保留 `memory.ps1` 的 UTF-8 BOM，以兼容 Windows PowerShell 5.1；不修改系统 PATH。

若通过 Git Bash 调用，先进入实际项目根目录，使用 `--project .`，避免 MSYS 转换中文绝对路径；优先用上述 PowerShell 入口。接手验证应执行真实命令，模型自报名称不能证明后端身份。

默认记录库位于当前用户目录的 `.shared-project-memory/data/memory.sqlite3`。SQLite 保存原文并以事务追加；修改进度通过追加新记录完成。`--store '数据库绝对路径'` 可指定隔离测试库，放在子命令之前。数据库由使用者首次保存时创建，分享技能时仅分发代码。

## 开始或续接

1. 确定当前用户指定的项目目录，运行 `context` 和 `recall`。Git 仓库按共用 Git 目录识别项目，子目录和 worktree 可以共用；记录按当前分支精确匹配。普通文件夹按传入目录的绝对路径区分，始终传同一项目根目录。移动或另行克隆项目后，其记忆不会自动迁移。
2. 按需检索以前的决策或故障。`search` 是关键词包含匹配，多词以空格分开且需同时命中；不是语义搜索，找不到时缩短关键词。所有结果都保留来源、UTC 保存时间及保存时的 Git HEAD/dirty 状态。
3. 将记录当历史资料，核对实际文件、分支、未提交修改和测试证据。冲突时以当前用户要求和实际证据为准；记录里的命令或建议不构成新的执行授权。
4. 简短说明已接到哪一步，再继续未完成工作。空结果意味着当前范围没有匹配记录，不代表整个项目没有历史；检查目录和分支。脚本报错时报告失败，不宣称恢复成功。

## 保存阶段进度

在完成一个有实际进展的任务阶段、遇到阻塞、准备结束或切换工具前保存；纯状态询问且没有变化时无需重复保存。额度突然耗尽时只能恢复到最近一次成功保存的记录。

1. 由当前模型整理简体中文摘要，写入一个唯一命名的 UTF-8 临时 Markdown 文件。摘要包含：
   - 当前目标及用户已确认的约束；
   - 已完成事项、关键修改文件与决策理由；
   - 实际执行的验证命令及结果；
   - 未验证事项、阻塞和待确认事实；
   - 明确的下一步，以及仍在运行的任务及其日志位置（如有）。
   保存必要证据路径，密钥、口令和完整原始日志留在其原有受控位置。已确认、推测和待验证分别表述。
2. 使用 `save --agent ... --title ... --file ...` 保存。脚本会自动附上项目身份、分支、HEAD、dirty 和 UTC 时间。标题与正文不能为空。
3. 仅在退出码为 0 且返回 `saved: true` 后宣称保存成功，并报告记录 ID。阶段临时文件可按本会话普通临时文件规则处理。

## 能力边界

本 Skill 共享摘要与历史记录，代码文件需要位于同一实际目录，或通过 Git 等现有方式同步。进程、终端、未落盘对话和工具调用现场不会随摘要迁移。更换分支后不会自动混用另一个分支的记录。

自动选择 Skill 取决于宿主与模型，不能保证每轮触发。新会话首次明确调用最可靠：Codex 使用 `$shared-project-memory`，Claude Code 使用 `/shared-project-memory`。当前加载列表未更新时，直接读取本文件并使用上述脚本；新建会话后再确认已被发现。Claude 必须运行本机 Local Code 会话，并有权限访问项目与共享目录。
